# DESIGN LANGUAGE RULES (keep every post consistent with the profile deck)

- Header format: spaced-out caps, e.g. `R K N . S T R U C T ™`
- Section tag top-left or top-right: `0X / TOPIC` (matches ABOUT/SERVICES/WHY numbering)
- Item codes: `SVC-XX` for services, `OBJ-XX` for objects, `PRJ-XX` for
  client/B2B projects — carry these codes from the PDF straight into posts
  so the feed and the profile deck feel like one system.
- Footer line on every static post: `r k n - s t r u c t . c o m  ·  © 2 0 2 6`
- Palette/material: raw steel tones, high-contrast black/white type over
  photos, minimal color — let the material (stainless, welded seams) be the
  only "color." No stock graphics, no soft gradients.
- Captions: short lines, hard line breaks, sentence fragments over full
  paragraphs — mirror the deck's clipped tone ("Built for function,
  permanence, and precision.").
- Every caption ends with one clear CTA line + the Arabic line where noted
  (Cairo/Egypt audience response is stronger with a short bilingual CTA).
