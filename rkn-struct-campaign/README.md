# RKN.STRUCT™ — Egypt B2B Outreach Campaign

Start here: **CAMPAIGN_PLAN.md** — strategy, phases, target segments, and
the pre-launch checklist.

Then use:
- **CONTENT_CALENDAR.md** — 4-week Instagram post plan, written in the
  company profile's design language (spaced caps, section numbers,
  SVC-XX/OBJ-XX codes).
- **DM_SCRIPTS.md** — Instagram DM openers, follow-ups, and reply
  handling, per vertical (restaurants, clothing brands, wedding planners,
  hotels, interior designers, furniture brands, artists).
- **EMAIL_TEMPLATES.md** — cold email templates for the same verticals,
  for contacts better reached by email than DM.
- **PROSPECT_TRACKER.csv** — outreach tracker, pre-populated with real
  Cairo prospects found via research (business name, Instagram handle,
  fit notes) plus the pipeline columns to fill in as you work the list.
- **assets/RKN-STRUCT-OnePager.pdf** — trimmed 1-page profile (About +
  Services + Process + Why + Contact), styled in the same dossier design
  language, for attaching to cold emails instead of the full 12-page deck.

Source: `Company Profile` PDF (RKN.STRUCT B2B Capabilities Overview).

matchbox run for a wedding planner. This is real, delivered evidence that
RKN can do quantity, not just 1-of-1 — it's used across the wedding
