# NOTES ON SENDING THESE

- Send **1–2 openers per day per platform**, not all at once — this reads
  as outreach, not spam, both to the recipients and to Instagram/email
  spam filters.
- Warm up (like/comment) 2–3 days before each DM — skip this and reply
  rates drop sharply.
- Log every send in PROSPECT_TRACKER.csv (DM/Email Sent Date column) the
  same day, so follow-ups go out on schedule (Day 3, Day 7).
- For the wedding planner and matchbox-adjacent sends, attach a real photo
  of the matchbox project if you have one — it's the single strongest
  piece of proof in this whole campaign right now.
